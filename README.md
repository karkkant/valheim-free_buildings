Free Buildings
=========
Makes building pieces free. Other things like crafting and comfort items have normal cost.
Think of it like a lite-version of "No build cost"-option in game.

Notice: 
1) <ins>This mod is not server synced</ins>. Support is added in case I find a way to do it properly. 
2) <ins>Toggling the "unlock all build pieces" option off requires a game restart</ins> once it has been enabled. Otherwise the setting remains persistent across characters/worlds.
